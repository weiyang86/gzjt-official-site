## 本轮完成

- 桌面首页左栏的风景底层从左侧滑入，品牌、工具及分屏按钮分批淡入。按钮本身不横移，保持原点击位置；快捷面板使用短淡入。
- 首页标题、新闻卡片、文化专题、业务数据、联系内容及背景线稿分批进入。重新进入分屏时重播，保留原轮播、滚轮、触控、内部滚动、键盘切屏及 CMS 配置的顺序/显隐。
- 入口页、内页及旧 HTML 共用一个控制器。内页内容第一次进入可视区时播放，标题轻微上移，包含链接/按钮的内容只淡入，避免命中位置随入场移动；正文富文本不逐段拆分动画。
- 桌面内容时长 560ms，手机 400ms；每项错开 45ms，延迟设有上限。左栏底层 640ms、按钮 360ms、面板 220ms；线稿 600–900ms。卡片悬停和按钮按下补充轻反馈，不增加持续循环动画。
- 尊重系统“减少动态效果”，运行中切换该偏好也会立即结束本轮动画。键盘聚焦内容会立即显示。默认样式始终可见，脚本/动画不可用时保留内容；动画结束清理效果，另有超时取消兜底。
- 统一处理原 `.reveal` 隐藏规则和集团概况/荣誉的旧 `view()` 动画，避免新旧透明度叠加导致内容不显示。使用原生 Web Animations、IntersectionObserver 和有限的 DOM 变更扫描，不新增依赖或持续逐帧计算。
