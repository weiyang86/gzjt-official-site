# 新数据库建表字段清单

来源：通过 `ssh gw` 读取服务器容器 `gzjt-directus-db` 中 PostgreSQL 数据库 `gzjt_cms` 的当前结构。

用途：按 `新curd方法.md` 的统一接口方式迁移 CRUD 存储前，新数据库服务器需要预先创建下列表。若新接口只承接官网业务数据，可优先创建“业务表”；若还要完整迁移 Directus 后台、用户、权限、文件元数据和配置，需要同时创建 Directus 系统表。

共需创建 47 张表，其中业务表 14 张，Directus 系统表 33 张。

## 建表备注

1. 上表保留了当前 PostgreSQL 的字段类型、主键、默认值和外键关系；新数据库若不是 PostgreSQL，需要将 `json`、`uuid`、`timestamp with time zone`、数组等类型映射为目标数据库支持的类型。
2. Directus 文件表 `directus_files` 只保存文件元数据；实际图片、附件二进制文件仍需要单独迁移。
3. 若新 CRUD API 只服务官网前端和自建后台，通常业务表是必需项；Directus 系统表用于保留原 Directus 后台运行状态、账号权限、界面配置和历史记录。
