# 全站 UI 整改实施与验收

日期：2026-11-16。根据用户已批准的整改方案实施，参考蜀道官网的白底、方正结构、图片轮播与紧凑列表。基线 `b896d36`，沿用 `codex/feature-ui-optimization-20261113`、Run `run_df9467d252c7` 和原工作区的 3000 服务。仅本地提交，不自动推送或部署。

预览：<http://localhost:3000/home>、<http://localhost:3000/about>、<http://localhost:3000/news>、<http://localhost:3000/disclosure>。

## 实现范围

- 首页新闻由原大卡片网格改为左侧图片轮播、右侧分类和新闻列表；手机改为上下布局。沿用原已发布文章、置顶/排序、配置数量、栏目关联及链接。右侧完整承接原配置文章，轮播按原顺序选择最多三张可加载封面，不改 CMS 或扩展内容模型。
- 图片确认可加载后才进入轮播。只在新闻屏激活时按需检查封面；离开分屏停止检查和自动切换，避免在首屏预取全部原图。支持上一条/下一条、圆点、暂停、左右键和横向触摸；悬停、聚焦、页面后台、分屏隐藏和减少动态效果均停止自动切换。
- 客户截图中的重叠标题已定位：封面图片本身含有标题，旧页面又把标题覆盖在同一区域。本轮完整显示原图，题注放到图下方，每帧只有一个当前题注节点，切换不保留两层文字。
- 首页新闻、文化、业务和联系采用同一浅色内容基线。原背景配置仍保留，照片和线稿降为轻量装饰；修正“后台背景有效时强制白字”的旧规则，保证测试环境有完整素材时仍可读。保留首屏、侧栏、全部分屏顺序/显隐、文化、专题、业务数据、联系、二维码及友链。
- 公共字体、字号、红灰配色、按钮、导航、分类、边框和小圆角统一；移除旧共享升级块中冲突的渐变、大阴影及上浮规则。导航保留全部栏目和间距规则，Logo 仅通过 CSS 裁去原图空白画布，未修改 Logo 文件或图形。
- 集团概况等单页保留内容，收敛标题和容器样式；新闻、公告、组织、项目、搜索、招聘、下载、联系等模板共用同一基线。下载模块的独立样式同步处理。
- 新闻列表缩小装饰横幅和重复说明占位，保留分类及分页；公告改为紧凑文字行，封面仍在相应详情内可达。手机分类使用可横向浏览的导航，保留全部分类和键盘入口。
- 详情标题/来源日期前置，真实封面放在标题后；正文已包含同一封面时不重复插入封面。标题采用均衡换行，避免手机长标题末行只落一个字。正文阅读宽度为 860px，富文本内联字体、对齐、表格、段落、图片和附件不重写。
- 修正公示详情也使用 `/news/:id` 时出现的两个一级菜单同时高亮：优先采用页面提供的栏目上下文。路由与跳转不变。

## 保留记录和范围限制

- 公告首屏优化前两次预检仍较低，原因是十多个分类全部平铺；记录原截图后，将通用手机分类切换为横向浏览，保留全部栏目。未无限压缩字号或反复叠加同类修复。
- 第一次轮播验收脚本的 CSS 属性选择器引号错误已纠正，原日志保留在 `interactions-harness-error.log`；不是页面运行错误。
- 手机补查第一次在 600ms 的抑制时限之后才发出合成点击，错误地期待该正常点击仍被拦截。保留 `delayed-click-test.log` 与 `final-qa-initial.json`，改为同一次调用中连续发出滑动和即时点击后通过；没有据此修改产品逻辑或隐去失败记录。
- 首轮 HTTP 读检曾有一篇文章返回 404，历史内容读取稳定性问题继续保留；不把 UI 和本地图片恢复称作数据源故障根因修复。
- 同一整合工作区由协调者集中写入并自验。原成功 Worker 和后续失败 Worker 均已退出、终端释放，本轮没有活跃 Worker、没有假设新 Worker 继承当前权限，也未创建新 Run 或其他项目任务。
- 原 CMS 中的示例业务名称/介绍、素材内容本身及经营数据未擅自替换。正式内容完善仍应通过原后台处理。
- 浏览器视口与合成触摸检查不等于手机实机或 VoiceOver 实测。
